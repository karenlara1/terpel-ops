#Proyecto Final – Terpel Ops

Este proyecto consiste en la implementación de un nodo de soporte tecnológico para la operación regional de Terpel en el Quindío, desarrollado como parte de la asignatura Administración de Infraestructura de TI de la Universidad del Quindío.

La solución utiliza Ubuntu Server 24.04 LTS y permite centralizar servicios de infraestructura como NTP, NFS, NIS, CUPS, Samba y DNS. Además, incorpora Dokploy, Docker, Nginx, Traefik y PostgreSQL para el despliegue y administración de un portal web de operaciones.

El proyecto incluye la configuración de servicios, medidas de seguridad, respaldos, monitoreo y pruebas de funcionamiento en un entorno de laboratorio.
